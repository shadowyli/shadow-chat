# 影聊 1.1.9 测试版发布说明

日期：2026-11-02。基线：1.1.8。适用：Windows 10／11，x86 客户端；
本轮交付环境为 `local`、通道为 `test`，默认从本仓库 GitHub Releases 检查对应更新。
影聊是 shadowyli 个人维护的开源局域网通讯软件。

本轮变更说明如下；附件和最终校验信息以实际发布的 `v1.1.9-test` Release 为准。

## 新增与改进

- 表情收藏浮层在输入区表情按钮上方展开，支持本地收藏、最近使用、搜索、管理和 ZIP 导入；
  点击外部或 Esc 收起。聊天图片和未发送的图片草稿都可添加到收藏，
  收藏保存独立原图并去重，保留会话草稿和发送失败重试。
- GIF 收藏、发送和历史展示保留原始动画。表情最长边限制为 **120 逻辑像素**，
  保持比例且不放大小图；普通照片使用独立展示规则。
  精简表情格文件名和重复说明，导入记住有效目录，取消不覆盖记录。
- 输入工具增加 Aa 格式栏及图片／视频入口，支持标题、常用字体样式、文字与高亮色板、
  链接、列表、引用及代码。截图菜单保留截图、自动隐藏偏好与 Windows 系统录屏入口。
- 修复窗口拉伸和大量动画内容时的重复测量与解码，追加消息避免全量重排；
  气泡随实际内容贴合，修正 DPI 变化、多图、头像、时间和昵称的布局。
- 新增影聊内嵌视频预览，使用随包 **libVLC 3.0.24 win32**，
  支持本地视频播放／暂停、双向进度拖动、结束重播和明确错误反馈，无需额外安装播放器。
  GUI 视频输出最大 **1920×1080**，待交付 GUI 帧最多保留一帧，避免界面慢时无限积压。
- 聊天记录覆盖在聊天区右侧，打开／关闭不挤压正文宽度。
  图片与视频按日期分组，以**每行两张、两列网格**显示，
  媒体格不重复显示文件名和日期；保留真实目标及筛选排序。
  “查看上下文”按稳定记录键定位对应消息，同正文的不同记录分别定位，
  不修改草稿或原始存档，仅有归档的会话只读展示。
- 点击消息、标题及可用会话头像查看已有公开资料；完善边界约束、关闭和缺失资料处理。
  修复统一弹窗右缘裁切，整理历史与搜索页签。
- 正常托盘和通知使用影聊图标，未读使用静态专用图标，继续禁止交替闪烁和任务栏关注闪烁。
- 移除普通成功、排队、离线重发和完成过程中的重复提示，图片不再追加重复文件卡片；
  保留真实队列、重发、附件入口、气泡进度和明确的静态失败反馈。

## 继承行为与升级

- 保留 1.1.8 的默认开机启动及设置入口；升级尊重已经关闭开机启动的偏好，
  卸载清理对应启动项。
- 更新仍为建议更新：只有发现本通道、本环境更高版本才提醒，每天最多一次。
  更新服务失败不阻止启动、登录、聊天或文件传输；“立即下载”指向对应 Release 安装包附件。
- 覆盖升级前退出托盘中的影聊，再运行安装程序。升级保留安装目录外的账号资料、
  本地聊天记录、接收文件与待发送队列；重要资料建议备份。
  本机合成资料的 1.1.8→1.1.9 升级已验证，不能外推为任意用户资料均已实测。
- 本地账号不提供云端历史同步或邮箱所有权验证。与旧客户端互通时保留可读纯文字正文；
  完整富文本与表情呈现仍取决于对端能力。

## 视频运行库来源与许可

新增视频运行库由固定的官方 VLC **3.0.24 win32** 归档提取，未改动原二进制。
随包路径为 `video-runtime/`；实际 `runtime-manifest.json` 列出 **308 个文件、
104,837,717 字节**，manifest 自身另计。这是新增运行库文件的字节合计，
不是安装包压缩后大小，也不是整个安装目录大小。

- 固定二进制来源：`https://download.videolan.org/pub/videolan/vlc/3.0.24/win32/vlc-3.0.24-win32.zip`。
- 对应源码：`https://download.videolan.org/pub/videolan/vlc/3.0.24/vlc-3.0.24.tar.xz`；
  官方源码校验及依赖源码索引记录在 `video-runtime/runtime-manifest.json` 的 `sources`。
- 源码与许可说明：`video-runtime/SOURCE-AND-LICENSES.txt`。
- 许可原文：`video-runtime/COPYING.txt`、`video-runtime/COPYING.LIB`；
  原作者说明保留在 `video-runtime/AUTHORS.txt`、`THANKS.txt` 和其他原始说明文件中。
- VLC／插件与 libVLC 的许可分别按随包原文适用，不把全部运行库概括为一种许可证。
  GPLv3 软件许可、原有 BeeBEEP 作者版权和实际第三方许可继续保留；
  见 [LICENSE.txt](../LICENSE.txt) 与 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。

## Release 附件与校验

- 安装包：供 Windows 用户安装或覆盖升级；本地暂存名为
  `影聊-1.1.9-test-x86-安装包.exe`，最终下载名称以本次 Release 实际附件为准。
  更新识别按发布规则使用 `ShadowChat-1.1.9-local-setup.exe` 等对应环境名称，
  不能仅给旧包改名冒充本轮产物。
- 完整源码归档：对应本次最终发布提交，包含软件源码和必要许可，
  不包含个人资料、本机测试账户或构建缓存。
- `build-info.json`：记录最终源码身份、构建环境、依赖、附件实际大小和摘要、
  验证范围及仍存在的限制。
- `SHA256SUMS.txt`：校验实际上传的安装包、源码和构建信息。

最终附件字节数与 SHA-256 由主发布流程读取定稿产物后写入
`dist/github-release/` 的最终发布说明、构建信息和校验清单。
本源码说明不固定中间安装包摘要，不把尚未生成的源码附件写成已交付。
发布规则见 [VERSION-RELEASE-POLICY.md](VERSION-RELEASE-POLICY.md)。
