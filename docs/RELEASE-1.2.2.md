# 影聊 1.2.2 测试版

环境 local，通道 test。本版通过 GitHub prerelease 提供给真人做小范围回归，
不等待真人验收后才发布测试包，也不将本机验证写成真实三机验收通过。

## 本轮修复

- 正常群聊送达确认不再追加系统消息；旧回执在现代聊天视图隐藏，保留队列及失败反馈。
- 表情 ZIP 与解压总量各不超过 1GiB，单项仍不超过 16MiB、条目不超过 5000。
  导入逐项校验和暂存，后台显示进度，原图不重编码，失败不提交新索引。
- 公共菜单使用无边框透明窗口，并清理透明画布，修复 Windows 黑色外框。
- 表情面板及共用弹层减淡叠加阴影，保留圆角与轻量层次，不再显示厚重深色描边。
- 左侧导航栏使用 `#030a0a`，选中导航按钮使用 `#e93d34`；保留白色图标和文字，不更改发送按钮配色。
- 主菜单新增“我要换座位”：先导出 `影聊_换座位历史记录_<账号>_<日期时间>.zip`，
  成功后清除本机此账号的密码校验及自动登录并回到登录页；保留原账号和聊天记录。
  取消或备份失败不会退出、不会清除密码。ZIP 未加密且不含接收附件，请妥善保管。
  新电脑解压后从登录页恢复工作区并设置新密码；原电脑重登已清理的账号需要负责人恢复密码。
- 连接与安全入口改为影聊状态对话框，显示本机实际监听和已验证联系人；
  诊断日志默认收起，关于及第三方许可继续保留上游归属。
- 修正回环网卡标志判断，增加不含消息正文的逐对端连接诊断与只读采集工具。
- 修复群配置先于成员握手到达时的成员遗漏；握手成功后安全重试原配置，不创建未验证联系人，
  不重放已经被修改、解散或离开的旧群配置。
  此项不代表已经找到同事之间无法互通的真实根因。

## 更新、安装与安全

仅建议更新，不自动安装、不强制升级。覆盖升级前正常退出影聊，并备份工作区。
本测试版没有商业代码签名；SmartScreen 可能仍因未知发布者或信誉不足提示风险。
改版本号不是消除 SmartScreen 的方法，也不代表 Defender 判定文件安全。
不得要求测试者关闭安全软件、添加排除项或绕过企业策略。

## 验收边界

本机自动验证结果以发布附件 verification.json 为准，真实三机结果不预填通过。
原生桌面截图可能受接口限制：本轮部分 GDI 截图整片黑色，WGC 捕获超时；
Windows 窗口样式和透明像素检查不能冒充最终桌面截图，菜单与弹层实屏效果仍需人工复核。
真实 Windows 10/11、三机六向发现与私聊/群聊、重连及重启仍需真实测试。
三台电脑使用同一 SHA-256 包体，在故障出现时采集 A/B/C 诊断。
诊断不采集聊天数据库、附件、账号配置和原始日志，但包含网络地址，应私下提供。
覆盖升级的数据文件保留与旧资料完整解析分开验收；无影聊身份标记的旧联系人缓存仍按既有
安全策略过滤，不作为已验证联系人显示。三台测试电脑应统一安装本包并重新连接。
