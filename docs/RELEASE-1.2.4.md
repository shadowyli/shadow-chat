# 影聊 1.2.4 测试版

环境 local，通道 test。供小范围真人复测，不提升稳定版、不覆盖旧版本。

## 更新内容

- 左侧导航未选中时图标与文字统一为灰色，选中底框改为浅白色；消息、通讯录使用面性图标，
  保留红色选中提示及键盘焦点，不改发送按钮。
- 修正图标着色的设备像素倍率，避免 150%／200% 缩放下图标意外缩小。
- 资料卡直接点击头像选择替换图片，移除旁边的铅笔按钮；选择后仅更新草稿，
  点击保存才提交，取消选择或取消资料编辑不会覆盖原头像。
- 全局搜索分类标题和数量不再重复绘制；搜索与聊天记录摘要移除经过核对的历史显示头，
  姓名、时间由元信息区域显示，用户正文中的同类文字不误删。
- 聊天记录的图片、视频摘要不再显示自动生成的文件名及正常传输流水，
  保留缩略图、用户说明、真实文件目标和失败反馈；普通文档仍显示文件名。
- 聊天中的视频改为小型静态播放卡片，点击使用现有内嵌播放器，不直接显示文件名和文件大小，
  不在后台自动解码或播放整段历史中的所有视频。
- 聊天记录去掉结果列表的内层边框，保留外侧面板与两列媒体布局。
- 表情包从聊天记录“图片和视频”列表排除，消息记录、原始文件和上下文继续保留；
  使用明确表情标记或本机表情库来源判定，不仅凭哈希文件名或图片外观过滤普通照片。

## 安装与安全

退出托盘中的旧程序，再覆盖安装本测试版；重要账号、记录及表情建议先备份。
只建议更新，不强制安装。旧版标签和附件保持原样。
本包未取得商业代码签名，SmartScreen 信誉提示可能仍出现；不要关闭防护或绕过公司策略。

## 验证边界

本机合成资料、隔离进程、原生 Qt Windows 窗口和安装数据保留检查以随包 verification.json 为准。
这些结果不代表真人多机验收。实际头像选择窗、办公网络及多人收发仍需反馈电脑复测。
旧资料中没有可靠表情标记、又无法关联本机表情库的图片保守保留，不误删普通照片。
视频小卡片使用静态播放封面，不宣称已经获取每个历史视频的真实首帧。
旧短文本气泡高度异常仍待定位，本版不宣称修复该问题。
