# 影聊 1.1.6 测试版

发布日期：2026-10-30。本次交付为 Windows x86 的 local/test 安装包。

## 新增

- 聊天记录改为主窗口右侧面板，提供消息、文件、图片和视频、链接分类，以及关键词、发送者、日期和时间排序筛选；可在面板内查看上下文。
- 消息右键支持回复：输入区预览原发送者和引用内容，可取消；发送后引用位于聊天气泡内部。
- 登录页提供 19 种常用邮箱后缀，包含 `@corp.netease.com`（corp 邮箱），同时保留完整邮箱和自定义后缀输入。

## 改进

- 欢迎页仅保留名字和头像设置，点击头像直接选择图片，删除额外选择按钮和两块说明卡片。
- 弹窗阴影更淡、更集中；最小化、最大化和关闭图标采用统一细线；下拉框使用白色、浅蓝和细边框。
- 默认窗口约 1120×820，支持拖动四边及四角缩放；保持统一圆角。
- 图片和截图使用圆角气泡；截图编辑、原图查看、发送反馈继续保留。
- 置顶区仅显示真实置顶会话，移除固定文件入口；无会话页面删除重复说明，按钮改为“前往”。
- 视觉提醒保持静态，不闪烁；使用发现更高版本后的非阻塞更新建议。

## 修复

- 正文、引用和失败反馈按会话分别保存，避免切换聊天后把上一人的草稿发给当前对象。
- 回复只在当前消息范围定位原文；点击发送者标题不再引用前一条，系统包装的图片保留真实发送者。
- 收到新消息时，聊天记录面板保留选中记录、结果位置、上下文页面和阅读位置。
- 退出账号使用统一确认框，正文与按钮完整显示，不再出现背景透明、内容与底层重叠的问题；默认操作为取消。
- 保留 1.1.4 首次登录窗口的不透明背景、系统边框及完整表单尺寸修复。
- 首次设置完成全部表单后再应用弹窗装饰，避免提前布局导致内容缺失和主窗口被隐藏模态窗口阻挡。
- 首次使用填写有效邮箱和至少 6 位密码后，点击“登录”自动创建本机账号。
- 已有账号继续使用原密码，错误输入不会重置原账号。
- 账号或登录状态写入失败时显示原因并留在登录页，允许修复存储权限后重试。

## 系统、安装与升级

适用 Windows 10/11，x86 应用，可在 64 位 Windows 上运行。
提供 local/test 当前用户安装包，包含配套 Qt、TLS 和 C++ 运行库。
本包的更新源为 `http://127.0.0.1:5173/updates/shadowchat.json`，用于本地测试；
本地版本服务未运行时，检查更新失败也不会阻止使用。
公开 dev/main 构建继续从本仓库 GitHub Releases 读取对应通道版本，不能将本地包改名分发为正式包。

退出现有托盘程序后运行安装包覆盖安装。
保留安装目录外的本机账号、聊天记录、接收文件和待发送队列。
已经运行的旧程序应先关闭，避免文件占用导致安装被拒绝。
邮箱后缀只是输入辅助：本机账号不验证邮箱所有权，也不连接 corp 邮箱认证或提供云端历史同步。
新版建议或版本服务失败不得阻止登录、聊天及文件传输。

## 验证范围

- 原生登录与首次设置、邮箱后缀、聊天记录和引用回复在 100%、150%、200% 缩放下验收；额外覆盖消息正文／引用隔离、失败保留与重试。
- 本机 TCP 对端实际接收文字、编辑后的截图和文件；图片引用与发送气泡、截图编辑、边框缩放及历史刷新回归通过。
- 安装、已发布 1.1.4 覆盖升级、重复覆盖、快捷方式图标、文件锁定拒绝、卸载重装，以及安装目录外的合成账号／记录／文件／待发送队列保留通过。
- 包体 TLS 运行库验证覆盖可信本地 HTTPS 成功、不可信证书被拒绝，未向系统信任库添加测试证书。

## 已知限制

本次在当前 Windows 10 主机及独立合成资料中验证。
本机合成测试不替代反馈电脑复测、干净 Windows 虚拟机或真实办公多机网络验收。
Windows 11 和真实办公网络仍需单独验收；本机测试对端回执不等于真实同事已收到。
本次未自动合并 PR，也未部署 main。详细结果以随包 `build-info.json` 为准。
