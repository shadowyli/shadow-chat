# 影聊 1.2.1 修复版说明（真实三机验收中）

<!-- release-status: real-three-pc-pending -->

## 更新内容

- 增加影聊客户端身份标识，只发现、展示和连接已通过影聊身份握手的客户端。
- 过滤 BeeBEEP、旧同源客户端和身份未知的缓存用户，避免“能看到但无法对话”。
- 改善多网卡及网络重新配置后的本地网卡选择和广播地址刷新。
- 增加安装启动诊断和真实三机只读诊断采集，定位机器特有的双击、运行库、安全策略和发现问题。

## 安装问题现状

1.2.0 的最终安装包在当前机通过命令行、ShellExecute 和 QA 隔离安装均可启动，下载文件大小与 SHA-256 正确。当前机存在指向未知旧程序的历史快捷方式；此前“双击安装包无法打开”尚未稳定复现，因此 1.2.1 不做无证据的安装器改写，改由诊断脚本记录实际文件、来源标记、窗口、事件和安全策略。

## 验收要求

- 最终验收必须使用同一个 1.2.1 候选安装包，在 A、B、C 三台真实 Windows 电脑上执行。
- Qt Test、offscreen、合成用户、回环网络和模拟客户端不得作为最终交付结论。
- 三台电脑必须完成六向发现、六向消息收发，以及 BeeBEEP／旧同源客户端不显示的检查。
- 当前版本处于候选阶段，真实三机结果未填满前不得发布 `v1.2.1-test`。

真实测试表见 [QA-1.2.1-REAL-3PC.md](QA-1.2.1-REAL-3PC.md)。

当前三机候选包 SHA-256 为 `32d4d9e4dceba5d4b47a8dd118e05a9486b89e128c546b5b3bb0c3f6042a4ad9`，仅供 A/B/C 真实验收。完成矩阵前不作为公开 Release 发布。

## 分发形式

- 安装版用于正式安装和覆盖升级，会创建卸载入口，并按用户设置管理快捷方式与开机启动。
- 便携版完整解压后直接运行，不写入安装信息，不创建快捷方式或开机启动项。
- 两种包体必须来自同一份已验证载荷，并分别记录大小和 SHA-256；便携版不作为规避安全软件检测的方案。
