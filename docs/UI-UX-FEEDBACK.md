# 影聊客户端 UI / UX 反馈与验收

本文件只记录 shadowyli 个人维护的影聊开源客户端。日期按 Asia/Shanghai 记录。
本发布副本根据开发记录整理，保留软件反馈编号与必要历史；编号不连续。
表内为需求摘要，不逐字转录用户资料或私人截图位置。

1.2.0 候选基于已合并的 1.1.9 提交整合。历史记录、开发预览、最终生产对象测试和安装升级验证分别记录；
“通过”只适用于注明的环境与场景，不表示用户已确认全部视觉，也不表示真实办公网络已验收。
上一版本说明见 [RELEASE-1.1.9.md](RELEASE-1.1.9.md)。
