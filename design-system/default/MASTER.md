# 影聊设计系统

> 桌面客户端的具体规则以 `pages/desktop-shell.md` 为准。工具站后续复用同一品牌色与信任表达，但不照搬桌面布局。

## 产品原则

影聊是面向公司局域网办公的即时通讯工具。界面优先支持三个高频动作：找到同事、打开会话、发送文字或一组图片。视觉应安静、清楚、可靠，不以装饰感制造“高级”。

设计刻度：变化度 4/10，动效 3/10，密度 6/10。

## 基础令牌

|---|---|
| 品牌 / 焦点 | `#2563EB` |
| 品牌悬停 | `#1D4ED8` |
| 深色导航 | `#172033` |
| 画布 | `#F5F7FB` |
| 表面 | `#FFFFFF` |
| 弱化表面 | `#F2F5F9` |
| 主文字 | `#172033` |
| 次文字 | `#5F6B7A` |
| 边框 | `#E3E8F0` |
| 在线 / 成功 | `#16A66A` |
| 等待 | `#D99B22` |
| 错误 / 危险 | `#D75A4A` |

- 桌面字体：`Microsoft YaHei UI`，回退到 `Segoe UI` 和系统无衬线字体。
- 间距采用 4px 基准，常用 4 / 8 / 12 / 16 / 20 / 24 / 32。
- 普通控件圆角 8px，导航项 10px，仅欢迎卡片使用 16px。
- 主界面图标统一使用 Phosphor Regular；禁止用 emoji 代替功能图标。

## 交互规则

- 一个界面只使用蓝色作为主要操作色；绿色只表达在线或成功。
- 所有核心操作必须具备悬停、按下、禁用和清晰的键盘焦点状态。
- 状态不能只靠颜色表达，必须有短文本；错误或空状态必须给出下一步。
- 不使用会改变布局的悬停缩放，不使用玻璃、渐变、连续动画或装饰性大阴影。
- 信任文案应准确写成“聊天和文件在局域网内直连”，不得暗示软件能保护整台电脑。

## 交付检查

- [ ] 默认打开“最近消息”，不出现“频道”等旧术语
- [ ] Ctrl+K 搜索、导航和会话输入均可用键盘完成
- [ ] 窄窗口不横向溢出，列表与会话可往返
- [ ] 加载、空、离线、错误均有明确反馈和恢复操作
- [ ] 多图一次确认、一次发送，并在同一消息内纵向查看
- [ ] 长文本可展开，长文件名和长英文不会撑破布局
- [ ] 可选联网更新的范围和隐私边界在界面中说明
