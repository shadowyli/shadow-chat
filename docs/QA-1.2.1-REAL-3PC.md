# 影聊 1.2.1 真实三机协作验收

## 1. 验收边界

- 最终验收对象是同一个候选安装包在三台真实 Windows 电脑上的运行结果。
- A 为当前开发机，B、C 为同事电脑；三台电脑必须使用相同的影聊版本和安装包 SHA-256。
- Qt Test、offscreen、合成用户、回环网络、模拟客户端和单机多实例只能作为开发辅助，不能代替本清单的最终结论。
- 采集脚本只读取系统、网络、进程、端口、安装信息和影聊日志。它不会修改防火墙、注册表、网络、启动项或影聊用户数据。
- 测试前不要手动关闭系统安全软件。若安全软件拦截，应保留提示截图并记录产品名称和处置结果。

## 4. 测试前置条件

1. 三台电脑连接到需要验收的真实局域网，记录是否同一网段。
2. 关闭旧版影聊及其他同源客户端，确认任务管理器中没有残留进程。
3. 三台电脑安装同一个 1.2.1 候选包，并核对 SHA-256。
4. 三台电脑分别登录不同测试账号，昵称清晰标记为 A、B、C。
5. 启动影聊后等待 60 秒，不通过手动填写 IP 绕过自动发现。
6. 各电脑运行 `scripts\qa-1.2.1\Collect-ShadowChatDiagnostics.cmd`，输入本机角色 A、B 或 C。

## 7. 非影聊用户过滤

1. 在同一局域网保留至少一台运行旧同源客户端或其他非影聊客户端的电脑。
2. 分别在 A、B、C 的通讯录、搜索结果、最近联系人、头像列表和新建聊天入口检查。
3. 非影聊客户端不得出现在上述任何入口；历史缓存若存在，也不得显示为可聊天在线用户。

## 10. 诊断采集方法

双击：

```text
scripts\qa-1.2.1\Collect-ShadowChatDiagnostics.cmd
```

或在 PowerShell 中运行：

```powershell
PowerShell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\qa-1.2.1\Collect-ShadowChatDiagnostics.ps1 -Role A
```

可指定输出目录：

```powershell
PowerShell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\qa-1.2.1\Collect-ShadowChatDiagnostics.ps1 -Role B -OutputRoot D:\ShadowChat-QA
```

默认输出到当前用户桌面的 `ShadowChat-QA-1.2.1`。每次运行生成一个目录和同名 ZIP，提交 ZIP 即可。采集完成后先查看 `SUMMARY.txt`；脚本不会读取聊天数据库、附件、密码或账号凭据。

## 11. 最终结论

只有以下条件全部满足，才可写“真实三机验收通过”：

- 三台电脑使用同一候选安装包且 SHA-256 一致。
- 安装与启动清单无阻断失败。
- A/B/C 六个发现方向全部通过。
- A/B/C 六个聊天方向全部通过。
- B 与 C 能互相发现、搜索、打开资料并收发消息。
- 非影聊及旧同源客户端在三台电脑上均不显示为可用联系人。
- 网络重连、影聊重启和 Windows 重启后可以恢复发现。
- 三台电脑均已提交测试截图和诊断 ZIP。
