# 常见问题

[返回首页](../README.md) · [上手指南](GETTING-STARTED.md)

## 需要服务器或互联网吗？

核心聊天和文件传输在局域网内进行，无需中央聊天服务器。
访问 GitHub 获取更新和安装包需要互联网；更新服务不可用不阻止登录、聊天或传输。
不同 VLAN、VPN、访客网络或终端策略可能阻止设备发现与互连。

## 邮箱账号是公司账号吗？

邮箱仅作为本地账号标识，不验证邮箱所有权，也不向公司身份系统认证。
当前登录页只接受列表内的预设后缀。同一邮箱在另一台电脑上不会自动同步聊天资料。

## 忘记密码怎么办？

有团队恢复配置时，联系保管恢复密码的负责人，通过客户端恢复流程处理。
维护者无法从 GitHub 找回你的本地密码，也没有中央账号库。
如有工作区备份，也可使用 [导入流程](GETTING-STARTED.md#备份换机与升级) 恢复资料。

## 离线消息由谁保存？

由发送端本机队列保存。对方上线后，发送端也需要运行且能够连接对方。
文件源被移动或删除等情况可能导致发送失败，应按界面提示重新选择发送。

## 覆盖安装会删除记录吗？

账号、记录和接收文件位于程序目录外，覆盖安装保留这些资料。
仍建议在升级前导出工作区并核验备份。卸载程序也不等同于擦除本地资料。
具体升级范围以对应 Release 说明为准。

## 有 macOS、Linux、手机端或云同步吗？

当前仓库的影聊交付说明面向 Windows 10/11 x86。
上游遗留的平台文件不代表影聊已发布这些平台的安装包。
本项目不提供手机端、云端历史同步或云中转服务。

## 为什么版本显示 local / test？

构建环境和更新通道用于区分交付对象。普通 `local` 和 `dev` 构建使用 `test` 通道，
`main` 构建使用 `stable` 通道，各自查询匹配的 Release 安装包。
普通 `local` 包默认也从 GitHub 获取更新；显式配置本机端口的调试构建使用本机服务。

## 为什么 Windows 提示未知发布者？

当前测试包未进行商业代码签名。先确认来自本仓库 Release，并与同一发布的
SHA-256 清单核对。组织策略拦截时请联系 IT；不建议关闭安全软件以运行安装包。

## 本地保存是否代表数据已加密？

没有。本地资料与备份不加密，请配合系统权限和受控存储保护资料。
恢复权限等具体说明见 [SECURITY.md](../SECURITY.md)。
