# 影聊 1.2.0 测试版说明（待最终验收）

<!-- release-status: draft -->

1.2.0 当前处于整合后的最终验收阶段，尚未发布。交付目标为 `local/test`。
下列变化已经进入候选源码；最终构建、安装升级和发布校验结果在验收后补充。

## 更新内容

- 修复更新服务限流、超时后漏报新版的问题，增加无需 Token 的公开备用查询；
  核对版本、通道、环境、安装包名称、大小和摘要，并交叉核对发布校验清单。
  查询失败明确显示可重试，不把损坏或缺失的高版本信息当成“已经是最新版”。
- 设置中的“查看最新版本”立即显示进度与结果，更新说明可滚动阅读，
  下载按钮直接打开匹配的安装包附件；解决设置窗口遮挡更新结果的问题。
  自动检查错开请求时间，建议更新仍为更高版本每天最多一次，失败不占提醒机会。
- 整理“我的资料”的头像、昵称、账号、简介、生日和电话布局，
  移除“移除头像”按钮和重复邮箱说明。登录账号只读可复制；
  小窗口可以滚动，保存和取消始终可达，取消保留原资料。
- 生日未填写时显示明确空态；只有用户选择或清除才改变日期，
  已有生日继续保留。日历增加快速年份和月份选择，统一浅色、圆角、细边框与阴影，
  靠近生日控件展开并避让屏幕边缘。
- 统一自己头像卡、公开资料卡、表情、颜色及菜单等小弹层的触发位置与窗口跟随，
  完善屏幕边缘避让、窄尺寸滚动、键盘焦点、外部点击和 Esc 关闭。
  修复部分弹层卡面意外透明，以及表情缩略图格子显示后无法点击发送的问题。
- 默认开机启动与持久偏好保持一致，覆盖升级保留用户主动关闭的选择；
  修复启动命令与偏好不一致时重新保存未生效的问题。预览及隔离验证不修改真实启动项。
- 修复原生开发预览脚本与发布构建参数不一致的问题，复用实际客户端界面，
  合成资料和更新查询保持隔离。

## 安装、升级与数据

- 交付目标为 Windows x86 客户端安装包；Windows 10／11 的具体兼容性范围，
  应以本次实际验证记录为准。目前未完成 1.2.0 安装及系统兼容性验证。
- 覆盖安装前从系统托盘退出影聊，再运行本次安装包。重要资料建议先备份。
  安装目录外的账号资料、本地聊天记录、接收文件和待发送队列应予保留；
  本轮将使用合成资料验证，不据此承诺所有真实用户数据均已实测。
- **1.1.8 旧版用户需要手动下载新版安装包并覆盖安装一次。**
  旧版已安装程序的更新逻辑不会随源码更新而改变；不得覆盖或替换旧版发布附件。
- 更新保持**建议更新，不强制升级**。只有本通道、本环境发现更高版本时才提醒，
  每天最多一次；更新失败不阻止启动、登录、聊天或文件传输。
  “立即下载”应直接指向匹配环境的 Release 安装包附件。
- 从 `local/test` 转为正式 `main/stable` 时必须分别构建、验证和归档；
  不能改名或换标签将候选包提升为正式包。

## 附件用途与来源

生产输入冻结并完成验证后，先把文档改为实际结果再提交；
最终源码归档来自这次文档定稿提交。该提交相对构建提交只允许变更 `docs/` 和根 `README.md`，
版本 defines、生产输入 snapshot、exe 与安装包哈希必须完全相同；生产输入 snapshot 不得改写。

| 附件 | 用途及来源 |
| --- | --- |
| `ShadowChat-1.2.0-local-setup.exe` | 供 Windows 用户安装与覆盖升级；复制自本次 `local/test` 安装验证过的安装包，复制后重新计算 SHA-256。 |
| `ShadowChat-1.2.0-source.zip` | `git archive` 导出最终文档提交的完整受跟踪源码；逐个核对文件集合与 Git blob，不含本机缓存、未跟踪辅助脚本和个人资料。 |
| `build-info.json` | 同时记录构建时 `buildCommit`、最终 `sourceCommit` 及生产输入一致性证明，另含二进制身份、工具链、运行库、附件大小、摘要、实际回归结果和未测范围。 |
| `release-notes.md` | 来自最终源码提交的本说明，并附加该次实际附件信息及自动验证摘要。 |
| `SHA256SUMS.txt` | 前四个附件的 SHA-256 清单；自身不参与递归校验。 |

版本号、说明、下载附件及校验信息以最终 GitHub Release 为准。
此初稿不固定尚未生成的安装包大小、摘要或最终提交号。
除经过验证的纯文档提交外，源码、测试或构建输入变更均需重新冻结、构建和验收；
构建身份、安装包或源码 ZIP 的来源无法对应时，停止归档。不得把仍为初稿、
更新清单待补充或 QA 全部待测的文档归档为验收后的说明。

命令行校验示例：`certutil -hashfile ShadowChat-1.2.0-local-setup.exe SHA256`，
将结果与 `SHA256SUMS.txt` 中同名文件对应行比较。

## 验证范围与限制

目前 **1.2.0 产品构建、常规回归、原生 UI、TLS、视频实播、安装及覆盖升级全部待测**。
准备阶段只核验工具链和旧版依赖缓存的字节身份；不继承 1.1.9 的产品验收结论。
具体测试计划见 [QA-1.2.0.md](QA-1.2.0.md)。

- 计划在同一冻结生产对象上执行 Windows 原生专项及 100%／150%／200% 缩放组合。
  项目执行次数不等于断言个数，自动结果不替代人工视觉验收。
- 安装与覆盖升级计划分别覆盖 1.1.8→1.2.0、1.1.9→1.2.0；
  合成外部资料保留测试不等同于任意真实账号和历史数据均已实测。
- 真实办公网络、全新 Windows 虚拟机、Windows 10／11 全环境、
  系统原生文件选择窗操作和通知中心最终视觉仍需另外验证。
- VLC 缓存的来源与哈希可复核，不等于本版视频播放已经验证。
  不承诺全部编码、容器、损坏视频或 4K 输入均可播放。
- 发布及远程重新下载附件校验尚未执行，不包含在本次打包准备中。
