# 影聊 1.1.1 测试版

本版本用于小范围内网试用，尚待真实办公电脑与企业网络验收。

## 新增与改进

- 归档此前本地完成的账号隔离、私聊和群聊、离线消息与素材队列、逐人送达、
  历史分类检索、备份恢复及附件迁移实现。
- 更新影聊应用标识，统一个人资料、同事资料、建群、设置、聊天记录与文件传输界面。
- 个人资料先显示资料卡，编辑时展开所需字段。
- 完整源码、安装脚本与回归测试一并归档。
- 纳入本地表情存储、选择器实现及对应测试源码。
- 强制更新：启动及运行中复查版本，低于最新发布版本不得继续使用；校验失败
  停留在重试入口。更新需要手动下载安装，不提供跳过或稍后继续使用。
  运行中每 5 分钟复查；触发阻断后暂停收发并保存队列，即使重新校验成功也须
  退出重启，避免在已停止的网络状态中继续操作。

## 修复

- 修改本地或同事头像后，刷新已打开的聊天内容与联系人图标。
- 头像在重启后保持，清除头像后旧图不会恢复，各账号缓存独立。
- 改善离线状态下已知同事被空状态遮挡的问题。

## 安装与升级

使用本 Release 的 Windows x86 安装包。覆盖安装默认保留安装目录外的账号、
记录和附件；重要资料仍建议先备份。安装包包含 Qt 与程序目录内的 VC++ 运行库。
邮箱作为本机账号标识，不验证邮箱所有权，也不提供跨电脑历史自动同步。
旧客户端需先手动升级至本版，强制更新能力无法反向注入已发布的旧程序。

具体构建身份、安装包大小、SHA-256 和本轮验证结果见 Release 附件
`build-info.json`、`SHA256SUMS.txt` 与 `docs/RELEASE-1.1.1-BUILD.md`。

## 已知限制与待验证项

- 双机发现、防火墙、20 台真实工作站负载、Windows 10/11 与企业普通用户权限
  仍需现场验证；已有同机多进程与大文件测试仅证明相应本机测试范围。
- 桌面截图框选、系统提示音、通知和默认软件打开素材仍需人工确认。
- 群主离线期间的管理变更在群主重连后同步，不提供离线群主身份的第三方授权转发。
- 下载镜像中的暂存文件不代表已完成现场验证。
- 必须先部署公司版本清单和下载页再投入试用；无网或版本服务不可用时，
  本版按强制更新规则阻塞使用。
- 旧 1.1.0 本地安装包没有独立源码提交，不能以当前源码补造其历史版本标签。
