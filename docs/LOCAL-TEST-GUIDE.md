# 本地端到端测试

本文件是操作指南；具体通过项目以 delivery 验证报告为准。

1.1.1 起启用强制更新。开始真实客户端端到端测试前，先确认公司
`https://flowx.gz/updates/shadowchat.json` 已部署有效的最新已发布版本，
下载页和安装包可访问。仅启动本地 FlowX 不会改变正式客户端的固定版本源；
源不可用时客户端应阻塞并提示重试，不能以此跳过校验。

1. 打开本地 FlowX `/tools`，点击影聊，核对版本、文件大小、清单测试通道和 SHA-256。
2. 点击下载，运行安装包。默认当前用户安装，无需统一账号服务器。
3. 启动版本校验通过后，首次输入邮箱和至少六位密码，创建本地账号，设置昵称和头像。
4. 另一台内网 Windows 10/11 电脑安装相同版本，使用另一个邮箱。等待自动发现对方。
5. 双向发消息；截图、粘贴、拖入多图、文件及带子目录的工程文件夹；核对接收文件字节及同名自动改名。
6. 新建项目群，测试 @、引用、群主转让、退群；离线成员上线补发，退群后不补发旧素材。
7. 退出接收方，发送消息和文件；退出并重新启动发送方，再启动接收方，确认排队任务恢复。
8. 发送后移动源文件，确认失败提示；重新选择发送，不使用断点续传。
9. 重启后打开历史记录，测试消息/文件/图片和视频/链接分类、关键词、发送人、时间和排序。
10. 设置中导出工作区，可选包含附件；另一台电脑登录页填写原邮箱与新密码，从备份恢复，无需原密码。
11. 切换本地账号，确认原账号内容、通知和收发不会出现在新账号；清记录不删素材。
12. 覆盖安装新版，核对账号、聊天记录和素材保留；设置中的“检查更新”仅访问 FlowX 内网。
13. 使用隔离测试服务分别验证最新、过旧、未发布、格式错误、无网和超时。
    过旧及校验失败均不能进入聊天；下载、关闭窗口或 Esc 不能跳过检查。
    不要向公司正式清单写入虚假版本完成测试。
14. 验证运行中定时复查发现新版或失败后暂停收发，托盘或重连菜单不能绕过，
    退出后账号、记录、接收文件和待发送队列保留。

默认开机启动并自动登录上次账号；工位交接务必主动退出旧账号。备份包无需密码，持有者可以恢复；原始磁盘目录不加密。

团队统一恢复密码由负责人私下保管，安装包只包含加盐哈希配置；不要把负责人密码文本上传到工具站。

没有发现同事时先确认同一办公内网，使用网络重新检测和诊断；被公司策略阻止时请 IT 协助，不需自行改 IP。
