# 影聊 1.2.5 测试版

环境 local，通道 test。由本地反馈批次 SC-NEXT-001 达到阈值触发，小范围真人复测使用。

## 更新内容

- 修复旧消息归档转换带入默认段落上下留白和导出分隔换行，导致短文本气泡偏高的问题；
  仅调整显示转换，原始存档、已存正文中的空行与换行、引用、图片和文件目标保留。
- 聊天记录的消息列表改为更紧凑的自适应行高；普通短消息减少留白，
  长消息按实际内容完整展示，不缩小字体、不裁切正文。
- 聊天记录“图片和视频”的预览格统一为 1:1 正方形，两列布局保持；
  居中裁切只用于缩略图，原图与原视频不修改，点击仍打开原媒体。
- “关于影聊”改用统一圆角、浅阴影与关闭按钮的影聊对话框，保留版本、维护者、产品说明及许可与致谢入口。
- 空会话提示移除白底卡片与边框，保留图标、说明和“前往”通讯录按钮。

## 安装与安全

退出托盘中的旧程序，再覆盖安装；重要账号、记录与表情建议先备份。
只建议更新，不强制安装、不提升稳定版。旧版标签与附件不覆盖。
没有商业代码签名，SmartScreen 信誉提示仍可能出现；不要关闭防护或绕过企业策略。

## 验证边界

气泡问题已在合成的旧中文短消息归档中复现，并验证显示高度收紧，原存档不变。
这不等同于反馈电脑中的全部旧记录已经验收；实际历史、缩放、多人收发及重连仍需真人复测。
本机原生窗口、回归、安装数据保留及更新契约以随包 verification.json 为准，不写成真实多机验收。
