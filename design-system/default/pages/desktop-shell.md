# 影聊桌面壳层规范

## 信息架构

- 左侧导航：`消息`、`通讯录`；低频功能进入`更多`。
- 通讯录内部切换：`同事`、`群聊`。
- 默认广播会话统一称为`全员群`，不得出现“频道”或“所有用户”。
- 启动默认进入`最近消息`，搜索同时覆盖同事、群聊和会话。

## 布局

- 导航栏 80px，列表区推荐 320px、范围 272–380px，其余空间给会话。
- 宽度低于 900px 时，只显示列表或会话；进入会话后必须显示返回按钮。
- 会话头 72px，消息区使用浅灰画布，输入区固定在底部白色表面。

## 核心状态

- `连接中`使用琥珀色状态和“正在连接局域网…”文案。
- `已连接`使用绿色状态，并显示在线人数或“正在发现同事”。
- `离线/网络不可用`使用红色状态，提供“重试/重新连接”。
- 最近消息、通讯录、群聊为空时，说明原因并提供对应操作，不显示空白列表。
- 拖入文件时输入区显示蓝色边框和淡蓝底，放下或离开后恢复。

## 消息

- 本机消息淡蓝底，对方消息白底；姓名和时间使用次级文字。
- 一次发送的多张图片放在同一消息中纵向排列，保持原图比例，可点击查看原图。
- 超过 700 字的消息默认显示约 520 字摘要，并提供“展开全文”。
- 输入提示必须随发送键设置变化：Enter 发送时显示 Shift+Enter 换行；否则显示 Ctrl+Enter 发送。

## 可访问性与键盘

- 焦点顺序：消息 → 通讯录 → 更多 → 我的 → 搜索 → 同事/群聊 → 列表 → 会话。
- 快捷键：Ctrl+K 搜索、Ctrl+1 消息、Ctrl+2 通讯录、Esc 返回列表/清空搜索。
- 所有图标按钮提供中文 accessible name 和 tooltip，焦点边框至少 1px 可见。
