# 影聊 1.1.8 测试版

发布日期：2026-11-02。适用于 Windows 10/11，x86 应用，local/test 构建。

## 改进与修复

- 首次安装默认开启当前 Windows 用户的开机启动，可在软件“设置”关闭；覆盖升级保留已关闭的选择，卸载时清理本软件启动项。
- 文件提交成功的提示在 5 秒后收起；失败原因保留，切换会话不会恢复过期成功提示。
- 私聊联系人离线时头像置灰，恢复在线后显示原色；群聊头像保持原样。
- 图片和文件的传输状态显示在气泡时间旁：排队静态等待、发送中转圈、失败静态提示，完成后停止；可点击查看传输详情。聊天正文不再重复堆叠传输过程文字。
- 删除会话栏的连接状态条及占位，保留连接检测和重连功能；截图按钮改为剪刀图标。
- 邮箱名称与后缀同排，只允许列表内的 19 种预设后缀；粘贴受支持的完整邮箱时自动拆分，不支持的后缀明确拒绝。
- 登录主按钮改为“一键登录”，下方显示“未创建的账号将自动创建”，删除两处重复说明；已有账号继续校验原密码。
- 修复退出账号后重新登录时历史文字、图片和附件气泡丢失，兼容旧存档，恢复发送方向、时间、图片与引用。
- PSD 等附件保留文件气泡，图片说明中的原图链接继续可用。
- 新截图使用 `ShadowChat-Screenshot` 加时间与唯一标识命名；旧截图只清理展示名中的旧前缀，保留实际文件名和链接。
- 主窗口增加轻柔外阴影，随移动、缩放、最大化、最小化和还原同步，不抢焦点或拦截点击。

## 安装与升级

从托盘退出影聊后运行 `ShadowChat-1.1.8-local-setup.exe`，可覆盖升级 1.1.7。
账号、聊天记录、接收文件和待发队列保存在程序目录外；本次升级不迁移或清空这些数据。
此前使用不支持预设后缀的账号仍保留本地资料与自动登录状态；手动登录只接受本版列出的后缀。

继续使用 1.1.7 的 GitHub 更新与直接安装包下载逻辑，普通构建不依赖本机更新服务。
本版只接收 test 通道中对应构建环境的更新；更新失败不阻止登录或聊天。
包内包含 Qt、Windows x86 C++ 运行库和 TLS 运行库。

## 验证范围与限制

候选验证范围包括当前构建对象的历史跨进程重载、登录后缀与账号恢复、
传输显示和队列、截图命名、主窗口阴影行为，以及 GitHub 更新、1.1.7 覆盖升级、
合成数据保留、快捷方式图标和 TLS 运行库。实际执行结果、测试日志及附件摘要记录在构建信息中。

本机合成资料验证不等同于真实办公多机网络、干净 Windows 虚拟机和 Windows 11 验收。
主窗口阴影的桌面视觉仍需用户确认；未进行商业代码签名。
本测试版不自动提升为 stable 通道。

## 附件用途与校验

- `ShadowChat-1.1.8-local-setup.exe`：Windows x86 安装与覆盖升级程序。

- `build-info.json`：源码提交、构建环境、工具链、附件大小、摘要、验证结果及限制。
- `release-notes.md`：版本说明及附件精确大小。

与 `SHA256SUMS.txt` 中同名文件核对。源码归档来自本版对应的发布提交。
