# 影聊 1.2.4 本机验证

日期：2026-11-05。环境 local，通道 test，源码在独立 `shadowchat-1.2.4` 快照。

## 回归结果

| 范围 | 通过项目数 |
|---|---:|
| 100% 核心 UI、搜索、媒体、资料、工作组、隔离对端、换座位 | 10 |
| 100% 账号、登录、备份、队列、表情、历史与更新 | 19 |
| 150% 资料、媒体、搜索、弹层及历史布局 | 5 |
| 200% 资料、媒体、搜索、弹层及历史布局 | 5 |
| Windows libVLC 实际 H264 解码、播放、暂停、拖动、重播、错误及关闭 | 1 |
| 独立历史布局、两列媒体、缩略图预览、搜索和上下文联动 | 1 |

总计 41 个项目／缩放组合，不是断言个数。均使用 Qt Windows 平台和隔离 Win32 桌面，
没有切换用户输入桌面；资料、文件和记录均为合成夹具，原始存档不改写。

头像用例验证鼠标／Space 进入选择、取消选择、取消草稿及保存新图；
自动化通过 Qt 文件选择器完成，系统原生选择窗的最终实屏效果仍需人工复测。
视频播放用例使用真正生成的红／蓝 H264 文件，不以静态卡片代替解码验证。
视频聊天卡片本身使用静态播放封面，不预填获取真实首帧的结论。

历史测试验证明确标记的表情及其传输记录不进入媒体列表；
没有表情标记的普通哈希文件名照片仍保留。普通文件名、用户输入的文件名文字及图片说明不误删。
旧测试中的未标记联系人改为具备影聊身份标记的合成夹具；生产身份过滤没有放宽。
