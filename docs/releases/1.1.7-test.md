# 影聊 1.1.7 测试版

发布日期：2026-11-02。Windows 10/11，x86 应用，local/test 构建。

## 修复

- 点击“立即下载”直接下载 GitHub Releases 的对应安装包，修复打开本机介绍页或 Release 介绍页的问题。
- 普通构建默认从 GitHub 检查版本，不依赖维护者运行本地网页。
- 安装包内的软件主页统一指向 GitHub Releases。
- 增加 GitHub 版本记录响应容量，避免历史记录增加后更新检查失败。

## 更新与交接

- 测试版继续只接收 test 通道，正式版只接收 stable 通道；仅选择对应构建环境的有效安装包。
- 校验版本、发布状态、附件摘要格式和仓库地址，拒绝介绍页、源码包及其他仓库的下载地址。
- 更新失败不影响启动、登录、聊天或文件传输；不自动退出或运行安装程序。
- 后续维护者在仓库发布新 Release 并上传对应安装包即可继续维护，客户端不保存发布凭据。

## 安装与升级

已安装 1.1.6 或更早版本的用户，需手动下载本版并覆盖安装一次。
旧客户端的更新逻辑不会因网站或源码修改而自行改变。
从托盘退出影聊后运行安装包，账号、聊天记录、接收文件和待发队列保留在原程序目录外。
安装后后续更新可直接从 GitHub 获取安装包。

本包包含 Qt、Windows x86 C++ 运行库和 TLS 运行库。
显式指定本机更新端口的构建仅供隔离调试，不作为本次交付安装包。

## 验证范围与限制

验证记录随 build-info.json 提供，包括原生更新按钮、GitHub 版本解析、异常网络处理、
构建更新源、安装和从 1.1.6 覆盖升级，以及包体运行库与 TLS 检查。
本机合成资料验证不替代真实办公多机网络、干净 Windows 虚拟机和 Windows 11 验收。
本版未进行商业代码签名，Windows 可能显示未知发布者提示。
本次不自动合并 PR，不提升 stable 通道，不部署正式环境。

## 附件用途

- `ShadowChat-1.1.7-local-setup.exe`：Windows x86 安装与覆盖升级程序。
- `ShadowChat-1.1.7-source.zip`：发布提交对应的完整源码归档。
- `build-info.json`：源码提交、构建环境、工具链、摘要、验证结果和限制。
- `release-notes.md`：本次发布说明与附件精确大小。
- `SHA256SUMS.txt`：上述附件的 SHA-256 校验清单。

可用 `Get-FileHash .\ShadowChat-1.1.7-local-setup.exe -Algorithm SHA256`
与 `SHA256SUMS.txt` 中同名文件的摘要核对。
