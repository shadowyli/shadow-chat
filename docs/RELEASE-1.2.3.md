# 影聊 1.2.3 测试版

环境 local，通道 test。面向真人小范围复测，不是稳定版。

## 更新内容

- 左侧导航改为浅色底、红色图标；选中项使用淡底和更浅的红色图标，保留清晰焦点，不更改发送按钮。
- 昵称、个性签名、电话、工作组直接在资料卡内编辑，不再跳转到大幅“我的资料”表单。
- 修正昵称与编辑图标、资料行文字与操作图标的垂直对齐。
- 资料卡按“保存”统一提交，取消、Esc、关闭或点外部丢弃未保存编辑；账号只读，
  未编辑的生日、头像、昵称颜色和其他已有资料继续保留。
- 每个人填写自己的工作组，组织架构按收到的工作组自动分类；未填写的联系人仍显示“未分组”。
  可填写多个工作组，组织架构增加“编辑我的工作组”入口。
- 工作组通过现有点对点资料消息同步，不增加转发服务器，不开启“仅同组连接”，不修改既有网络策略。
  工作组即时同步请统一使用本包；旧客户端仍能接收基础资料，工作组可在正常重连握手后获取。
- 补齐更新回退所需的 `product`、`sourceTag`、`installer` 等发布元信息，
  并验证安装包与元信息的 SHA-256，避免 GitHub API 限流时因发布字段遗漏而无法检查更新。
  保留校验、版本及通道限制，不在客户端放置 GitHub 凭据。

## 安装与验证范围

仅建议更新，不强制安装。覆盖升级前正常退出影聊并备份工作区。
未取得商业代码签名，SmartScreen 信誉提示可能仍出现；不要关闭防护、添加排除项或绕过企业策略。
本机回归、资料字段保留、原生窗口缩放和安装校验以附件 `verification.json` 为准。
本机隔离进程及回环测试不代表真实办公网络验收；多人发现、聊天、群聊、工作组同步仍需真人复测。
新反馈中的旧文本气泡高度异常尚未定位，本轮未针对该问题修改，不将其写成已修复。
