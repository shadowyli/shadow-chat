# 影聊 1.2.6 真人复测

三位测试者使用同一安装包，先比对版本、包体大小与 SHA-256。
本机合成与隔离桌面测试不代替以下验收。

1. 先完成文件传输，再保持旧影聊运行并安装；确认影聊正常退出、安装继续，账号、聊天记录、表情、设置仍可读取。
2. 点击消息与通讯录，确认没有红色外框。用 Tab、Space 切换导航，检查焦点与选中状态。
3. 连续双向发送短中文、数字、引用后短文、带格式文字和表情；重启与重载历史后，检查是否仍有非人为留白。保留真正输入的空行。
4. 主菜单不再出现聊天存档、文件传输两项；聊天内历史入口与实际传输功能继续可用。
5. 关于窗口没有许可独立弹窗和底部关闭按钮，顶部叉号与 Esc 正常；100%、150%、200% 缩放下边角无白块。
6. 六向发现、六向消息、群聊及重连／重启均检查；故障时采集诊断，不关闭安全软件、不修改公司网络策略。

气泡再次异常时记录版本、缩放、是新消息还是旧历史、是否引用／粘贴／带格式；不要直接把私密聊天文件发到公开仓库。
