# 影聊 1.1.3 测试版

日期：2026-10-30。

## 改进

- 重新设计聊天界面：左右头像、圆角消息气泡、清晰时间与更大的输入工具按钮。
- 通讯录采用分类与姓名分组，支持查找联系人和进入会话。
- 全局搜索可切换联系人、群组与消息，支持键盘选择和定位结果。
- 会话栏增加常用入口、消息摘要及最近、未读、@我、待处理筛选。
- 个人资料采用紧凑资料卡，支持复制邮箱、编辑签名和电话、切换工作状态。
- 统一弹窗圆角、阴影和关闭操作，精简重复入口与旧界面。

## 修复

- 所有视觉提醒保持静态，停止任务栏、托盘和列表图标闪烁。
- 修复资料窗口首次打开显示不完整的问题，小窗口可滚动且操作按钮保持可见。
- 修改昵称、头像及个人资料不再往聊天中插入提示。
- 发送未成功时显示原因并保留输入内容；截图发送前可查看图片，失败保留预览。
- 更新“关于影聊”的产品信息，保留开源许可证及版权说明。

## 安装与升级

适用 Windows 10/11，x86 程序，可在支持 32 位应用的 64 位 Windows 上使用。
退出托盘中的影聊后运行安装包，覆盖安装保留外部账号、聊天记录和接收文件。
仅存在更高版本时建议升级；当前已是最新版不会自动弹窗。

## 验证范围与限制

这是 local/test 构建，用于本机安装验证；版本检查源为本地下载站。
不代表 dev/main 已部署，不建议分发为公司正式版本。
源码在独立目录冻结，仍在开发的截图编辑工具改造未纳入本版。
原生开发预览使用合成资料并隔离办公网络；真实办公多机收发仍需另行验收。
具体安装、升级、回归结果以随包 build-info.json 为准。

## 附件

- `ShadowChat-1.1.3-local-setup.exe`：Windows 安装程序，供安装或覆盖升级。
- `ShadowChat-1.1.3-source.zip`：对应标签完整源码，需自行编译。
- `build-info.json`：源码提交、构建环境、验证范围及程序／安装包摘要。
- `SHA256SUMS.txt`：附件字节数与 SHA-256 校验清单。

使用 PowerShell `Get-FileHash <文件名> -Algorithm SHA256` 对照校验清单。
