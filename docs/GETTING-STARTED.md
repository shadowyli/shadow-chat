## 选择安装包

影聊当前提供 Windows 10/11 的 x86 测试安装包。到
[Releases](https://github.com/shadowyli/shadow-chat/releases) 选择版本，
阅读其环境、通道、已知限制和实际测试范围。标记为 Pre-release 的版本仍是测试版。
安装使用不需要部署聊天服务器，但两台设备需要在允许互相通信的局域网内。

| 附件 | 用途 |
| --- | --- |
| `ShadowChat-<版本>-<环境>-setup.exe` | Windows 安装或覆盖升级 |
| `ShadowChat-<版本>-source.zip` | 对应版本的源码，普通用户无需下载 |
| `SHA256SUMS.txt` | 发布附件的 SHA-256 校验清单 |
| `build-info.json` | 源码身份、环境、工具链和实际验证范围 |
| `release-notes.md` | 版本说明和附件信息 |

以下为 1.1.8 的校验示例；其他版本请替换文件名：

```powershell
Get-FileHash .\ShadowChat-1.1.8-local-setup.exe -Algorithm SHA256
```

将输出与同一 Release 的 `SHA256SUMS.txt` 中同名条目逐字符比较。
不一致时停止安装并重新下载。摘要用于核对文件完整性，不等同于商业代码签名。
当前测试包未进行商业代码签名；遇到系统或组织策略拦截时先核实来源并联系 IT，
不要关闭终端防护。

## 完成第一次通信

1. 退出已有影聊进程（包括托盘），运行安装包，按向导完成当前用户安装。
2. 从开始菜单或桌面打开影聊。选择登录页列出的邮箱后缀，输入至少六位密码。
   未创建的账号会自动创建；已有账号仍需正确密码。邮箱不接收验证码。
3. 设置昵称与头像。在第二台同一内网的电脑安装并启动相同版本，使用另一个本地账号。
4. 等待通讯录出现对方，打开会话，双向发送一条文字和一个小文件。
   核对文件能够打开，之后再尝试多图、文件夹和群聊。

1.1.8 的手动登录仅接受登录页的预设后缀。
现有不受支持后缀账号的兼容行为见 [1.1.8 说明](releases/1.1.8-test.md)。

## 日常使用与数据

多张图片可以一起拖入发送区，确认预览后发送；消息和文件传输失败时留意界面反馈。
离线队列在发送端本机保存，对方上线后仍需发送端运行且网络可达。

默认资料位于 Windows 系统“文档”目录中的 `影聊/accounts`。
文档目录可能被系统重定向，请以实际位置为准。账号、聊天记录与接收文件在程序目录外保存。
资料的访问与保护方式见 [安全说明](../SECURITY.md)。

默认自动登录上次账号；首次安装默认启用当前 Windows 用户的开机启动。
可在设置中关闭，工位交接时应主动退出账号。

## 备份、换机与升级

通过“更多 → 工作区与换机”导出工作区，需要迁移接收素材时选择包含附件。
在新电脑使用导入流程恢复，并在确认数据完整后再清理旧电脑。
备份无需原账号密码即可恢复，请存放在受控位置，不要附在公开 Issue。

升级前先备份，从系统托盘退出程序，再运行对应新版安装包。
覆盖安装保留程序目录外资料，但仍应自行核验记录与附件。
不要把卸载当作清除聊天资料的手段。

更新来源为 GitHub Releases，按构建环境和通道选择版本。
`local` / `dev` 属于 `test` 通道，`main` 属于 `stable` 通道；不要靠改名切换通道。
普通 `local` 包从 GitHub 获取更新。只有更高的匹配版本才自动提醒，
每天最多一次；更新检查失败不会阻止登录或聊天，安装仍由用户决定。

## 找不到联系人

先确认双方程序正在运行、使用相同版本，且处于同一允许设备间通信的局域网。
检查是否连接了访客 Wi-Fi、VPN 或存在无线客户端隔离，并记录是否为单向可见。
在可用的网络诊断入口重新检测；如果防火墙、VLAN 或组织策略阻止通信，
请 IT 协助确认，勿自行绕过策略。

仍无法解决时按 [支持说明](../SUPPORT.md) 提交系统、版本、构建环境及脱敏复现步骤。
自行验证功能可参考 [本地测试指南](LOCAL-TEST-GUIDE.md)。
