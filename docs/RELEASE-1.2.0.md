# 影聊 1.2.0 测试版说明

<!-- release-status: ready-for-publish -->

交付通道：`local/test`。这是影聊个人开源项目的 Windows x86 测试版，发布附件以本次 GitHub Release 为准。

## 更新内容

- 修复更新服务限流、超时后漏报新版的问题，增加无需 Token 的公开备用查询；严格核对版本、通道、环境、文件名、大小和 SHA-256。
- 设置内“查看最新版本”立即显示进度和结果；建议更新只在发现更高版本时每天最多提示一次，失败不阻止使用。
- 优化“我的资料”、生日空态、日历、登录、默认开机启动和覆盖升级偏好保留。
- 统一资料卡、表情、日历、颜色、菜单等弹层的锚定、边缘避让、圆角、阴影、外部点击和 Esc 关闭行为。
- 修复 GIF、图片气泡、视频预览、历史上下文跳转、媒体日期分组、两列媒体布局、覆盖式搜索和发送失败反馈相关问题。
- 移除界面中的旧品牌残留，统一影聊图标、标题和通知资源；视频预览复用随包固定版本的 VLC 运行库。

## 安装、升级与数据

- 1.1.8 或 1.1.9 用户需要先退出影聊，再手动下载并覆盖安装本版。旧程序不会因仓库更新自动获得尚未安装的新代码。
- 本版保持**建议更新，不强制升级**：当前已是最新版不弹窗；发现更高版本时每天最多提示一次；检查失败不影响使用。
- 自动检查和“立即下载”只使用匹配的 `local/test` Release 信息，不把失败或损坏的高版本信息当成最新版。
- 安装验收使用隔离 QA namespace 完成；账号、聊天记录、附件、待发队列和设置保留，用户真实启动项、注册表和快捷方式未被测试修改。

## 验证范围与限制

本版通过生产构建、TLS 正负控制、常规回归、原生 Qt Windows UI（100%／150%／200%）以及隔离安装和覆盖升级。完整记录见 [QA-1.2.0.md](QA-1.2.0.md)。

仍需人工确认：Windows 原生文件选择窗和通知中心最终视觉、真实办公网络、全新 Windows 10／11 环境、物理多显示器跨屏，以及 4K／未覆盖编码媒体。合成账号、回环网络和本机夹具不等同于真实办公网络验收。
