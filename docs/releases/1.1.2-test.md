# 影聊 1.1.2 测试版

## 修复与改进

- 取消 1.1.1 的强制版本门禁。版本服务不可用、断网、超时或返回网页时，
  安装后的登录、聊天及素材传输继续可用。
- 只有检测到更高的同通道已发布版本才提示更新，每个本地自然日最多自动提醒一次。
  当前最新版本跨天或重启均不自动弹窗；升级后停止提醒旧版。
- 同日关闭提示、下载或重启不重复打扰，未升级时次日再提醒。手动检查不受频次限制，
  显示最新、新版或失败结果，失败可重试。
- 本地、dev、main 构建环境和更新通道明确区分，测试包不向正式用户推送提醒。
- 桌面、开始菜单及卸载入口使用随版本命名的独立红色图标，覆盖安装后刷新 Shell。

## 安装与升级

适用 Windows 10/11 x86 应用运行环境。下载本 Release 的安装程序，退出现有
影聊后覆盖安装。1.1.1 用户需手动下载升级，无需在旧版本门禁中反复重试。
默认保留安装目录外的账号、记录、接收文件和待发送队列，重要资料建议提前备份。
程序不会自动下载、安装、强制退出或因为更新失败停止收发。

## 附件

- Windows 安装包：直接安装使用；文件名标识实际构建环境与通道。
- 源码 ZIP：版本标签对应的完整 Git 源码，不包含私密资料和构建目录。
- `build-info.json`：源码提交、构建配置、环境、工具链、包体大小、SHA-256、
  验证结果及限制。
- `SHA256SUMS.txt`：安装包、源码包和构建信息的完整校验清单。

精确文件名和大小在实际发布时列于 Release。下载后可用
`Get-FileHash <文件路径> -Algorithm SHA256` 或 `certutil -hashfile <文件路径> SHA256`
与清单逐项比较。

本轮本地测试安装包为 36,472,694 字节（约 34.78 MiB），
SHA-256：`7f59a75bfae8b5d6e04d5af22307d07941fea7e2bb65dd1659b972c2f8266279`。
它包含生产程序、Qt/图形插件、x86 VC++ 运行库、兼容 OpenSSL DLL 及许可证、
公共说明与资源、独立版本化 ICO 和既有加盐恢复配置。不含个人账号、历史、
素材、队列、负责人明文密码或测试证书私钥。

## 发布顺序与验证边界

本轮交付为本地可用的测试版。先本地、再 dev 部署验收、最后 main 发布。
GitHub prerelease 不代表公司 dev/main 已部署；缺少部署权限时提供待执行材料。
main 部署与 PR 合并另需用户确认。main 如果重新构建，必须记录与 dev 的差异并重验。

本机/合成资料回归不替代真实办公多机、跨网段、防火墙、全部企业权限和 Windows
版本验收。Qt 5.15 的兼容 TLS 运行库需后续维护升级，既有非阻塞视觉警告应如实记录。

本地测试包使用 `local / test`，更新源为本机 `127.0.0.1:5173`；
未运行本机版本测试服务时自动检查安静失败，仍可使用影聊。
dev 包使用预发域名与 test 通道，main 包使用正式域名与 stable 通道。
不能把本地包改名后当 dev 或 main 包分发；如需切换环境，应重新构建并验证。
