# 影聊 1.1.4 测试版

日期：2026-10-30。

## 修复

- 修复首次登录窗口可能显示不完整、只剩邮箱输入框的问题。
- 登录页使用不透明窗口背景和系统窗口边框，避免透明窗口绘制影响首次使用。
- 首次显示前按完整表单计算尺寸，邮箱、密码、登录和创建账号操作完整可见。

## 安装与升级

适用 Windows 10/11，x86 应用。退出托盘中的影聊后运行安装程序覆盖升级。
安装目录外的账号、聊天记录、接收文件及待发送队列保留。
这是 local/test 测试构建；更新检测使用本机测试服务，服务不可用不阻止使用。

## 验证范围

具体首启、账号、缩放和安装结果见随包 build-info.json。
本机合成账号验证不能代替反馈问题的电脑复测。
本版不包含另一开发会话仍在进行的截图编辑器改造。

## 附件

- `ShadowChat-1.1.4-local-setup.exe`：Windows 安装与覆盖升级程序。
- `ShadowChat-1.1.4-source.zip`：对应标签源码。
- `build-info.json`：构建身份、验证结果与限制。
- `SHA256SUMS.txt`：附件 SHA-256 校验清单。
