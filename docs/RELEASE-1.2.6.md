# 影聊 1.2.6 测试版

环境 local，通道 test。根据 1.2.5 的测试反馈继续修复，不覆盖历史标签或附件。

## 更新内容

- 安装时请求目标安装目录中的影聊正常保存并退出，成功退出后继续安装；使用 Windows Restart Manager，不强制杀进程、不关闭其他安装目录中的影聊。无法正常退出或文件仍被占用时停止覆盖，允许重试或取消。
- 消息和通讯录导航不再在鼠标点击后出现红色焦点描边；浅白色选中底与现有图标颜色保留，键盘导航仍有中性焦点提示。
- 收紧富文本与纯文本的一致性校验，防止富文本额外空段把短消息气泡撑高；同步归零气泡内部段落的外边距，不删用户真正输入的空行，不重写已有聊天归档。
- 主菜单去掉“聊天存档”和“文件传输”两个入口，不删除聊天记录或文件传输功能。
- 关于窗口去掉独立“许可与致谢”按钮和旧弹窗入口，保留紧凑版权及 GPL 说明，以及安装包、源码中的完整许可证。
- 关于窗口只保留顶部关闭按钮，支持 Esc；公共对话框的白色内容层改为透明，避免覆盖圆角，使用抗锯齿边线和浅阴影。

## 安装与安全

安装包尚未商业代码签名，SmartScreen 信誉提示仍可能出现。不要关闭防护或绕过企业策略。
升级前建议备份重要数据并等待正在进行的文件传输完成。旧版本的退出保护能力取决于旧版本本身；本版不承诺接管旧进程正在传输的文件。
只发布测试渠道，不提升稳定版、不合并 main、不部署生产。

## 验证边界

富文本夹带额外空段的高度异常在未修改的 1.2.5 生产对象中复现；这只证明已定位的一条软件路径，不宣称反馈截图的所有存量记录已经验收。
合成数据、隔离桌面、安装与更新校验结果随构建回执归档。反馈电脑的旧记录、原生实屏边角及真人多机仍需复测；证据不足的问题保持待定位或待复测。
