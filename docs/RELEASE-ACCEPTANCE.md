# 影聊首版交付与验收

确认日期：2026-10-28；更新提醒要求于 2026-10-29 修订为 1.1.2 非阻塞策略。
本文保存需求，不代表实现或验收已完成。

## 产品与交付

- 20 人设计、美术团队，Windows 10/11，仅公司内网；一个当前用户可安装的安装包。
- FlowX 顶部“工具站”，软件列表、影聊详情与下载页面；视觉层级参考 IlluGen，沿用 FlowX 风格。
- 真实源码构建安装包；可下载、安装、启动、覆盖升级；账号、记录、附件独立于程序保留。
- FlowX 静态清单异步检查更新。只有更高同通道已发布版本可自动提醒，每天最多一次；
  当前最新不弹窗，检查失败不影响登录和收发。手动检查显示结果并可重试。
  下载后手动覆盖安装，保留账号、历史、附件和队列。1.1.1 用户需手动升级 1.1.2。

## 本地身份

- 邮箱作为本地标识，不验证邮箱，无中央服务器；首次创建邮箱密码账号、昵称头像。
- 每个账号单独数据目录；登录、搜索、通知、收发仅针对当前账号。
- 负责人设置统一安全恢复密码；可重置本机账号密码并保留记录，不预置公开通用密码。
- 默认开机启动和自动登录上次账号，可关闭；主动退出后不再自动登录旧账号。
- 换账号前提示未完成传输，退出停止旧账号收发；保留队列，下次登录重传未完成文件。
- 同账号同时在线仅提醒、不拦截；不同电脑历史不自动同步。
- 账号用于软件层隔离；用户接受磁盘可直接读取其他目录，不要求文件加密。

## 沟通与素材

- 内网自动发现，不手填 IP；私聊和项目群。
- 截图、粘贴图片、拖拽图片/文件/文件夹、引用回复、群内 @ 全部需要。
- 文字、图片、视频、PSD/AI/EXR/FBX 以及工程文件夹传输；最大单文件 5GB，保留目录结构。
- 所有素材自动接收，显示进度及失败原因；失败手动从头重试，不做断点续传。
- 同名文件加序号，永不覆盖；消息指向各自实际文件。
- 默认文档/影聊/账号/接收文件，可改目录；不自动删除，磁盘不足失败后手动重试。
- 多图一次确认、成组展示；原图无损，缩放平移、批内切换、文件名尺寸大小、透明背景、单张与整组保存、打开目录。
- 视频卡片，系统播放器打开；专业格式系统关联软件打开，不做内容预览；不做双图对比。

## 离线与群组

- 对方离线本机排队；双方运行后补发，退出重启保留。
- 文件队列只存路径/大小/修改时间，不复制素材；原文件缺失或变化明确失败，重新选择。
- 群内每个收件人分别排队及送达，显示送达人数与失败对象；必须是接收方确认成功。
- 任何人建群，群主改名、移除、转让、解散；成员邀请、退群。
- 群主离线不影响聊天传文件；成员重连同步群管理变化。
- 新入群仅见入群后内容；退群/移除取消未送达任务，重入不补旧消息；本地旧历史保留。

## 历史与迁移

- 本地历史持久化；消息/文件/图片和视频/链接四分类，无云文档。
- 关键词、发送人、时间、排序，结果定位到原聊天；文件打开和目录、媒体预览、链接复制打开。
- 移除会话仅隐藏；清空记录确认后执行，绝不删除接收的本地文件。
- 单文件压缩备份，个人资料、身份、联系人、群组、设置、聊天记录；附件可选并提示预计大小。
- 新电脑登录页可恢复，无需原密码；现有数据先备份，失败不能破坏原数据。

## 通知与界面

- 窄导航/会话列表/聊天区三栏；左右气泡头像时间、送达状态、大输入框；置顶免打扰。
- 关闭窗口进托盘继续收发；未读数、桌面通知、声音；免打扰群被 @ 仍提醒。
- 无管理员权限机器可安装；网络拦截时提供重试和可复制诊断，不要求绕过企业策略。
