# 影聊 1.2.7 测试版

2026-11-06。适用 Windows 10/11，x86 客户端；本次发布环境为 local，通道为 test。

## 改进与修复

- 设置窗口使用一致的白色背景，修复滚动内容的灰底及底部圆角被不透明矩形覆盖的问题。
- 保存、取消固定在窗口底部右侧；缩小窗口或出现较长的更新说明时，只滚动内容，按钮始终可见。
- 设置窗口适应可用屏幕范围，并保留统一的标题栏、边框、关闭和拖动缩放行为。
- 接收文件夹显示从路径开头开始，悬停可查看完整路径；实际保存路径与选择文件夹功能保持不变。
- 精简“关于影聊”，移除底部三行说明，保留软件版本、维护者和单一关闭按钮。源码版权、独立许可证入口和安装目录中的许可证文件保留。
- 继承 1.2.6 的功能，并纳入主线已合并的跨网段发现修复：按 UDP 端口识别发现目标，避免把包含 255 的有效 IPv4 主机地址误判为广播。

## 安装、升级与数据

从托盘退出影聊后运行 `ShadowChat-1.2.7-local-setup.exe`，可覆盖升级 1.2.6。
安装目录外的本机账号、聊天记录、收发文件和待发送队列继续保留；重要数据请先备份。
开机启动设置尊重已有选择，本次设置界面修复不更改用户的现有偏好。

更新采用同通道、同环境的更高版本建议，不强制退出或阻止使用；更新服务失败不影响启动、登录和收发。
本版是测试版，不自动提升为正式版本。

## 验证与限制

本版针对设置窗口、关于窗口和统一弹窗运行原生 Windows Qt 回归，覆盖 100%、150%、200% 缩放；
验证保存与取消、长路径、更新说明滚动、底部按钮可达性和圆角透明边界。
旧 1.2.6 生产对象已用于失败基线复现。最终构建、回归和安装升级结果以附件 `verification.json` 为准。

本机合成资料测试不等同于反馈电脑视觉复测、真实办公多机网络或全部 Windows 机型验收。
安装包没有商业代码签名，Windows 可能显示未知发布者提示。

## 附件与校验

- `ShadowChat-1.2.7-local-setup.exe`：Windows 安装及覆盖升级程序。
- `ShadowChat-1.2.7-source.zip`：最终发布提交的完整源码和许可证，不含用户资料或构建缓存。
- `build-info.json`：源码提交、版本、环境、编译工具、安装包和源码归档摘要。
- `verification.json`：实际运行的回归、安装和升级结果及测试范围。
- `release-notes.md`：本版本说明的离线副本。
- `SHA256SUMS.txt`：各附件的 SHA-256 校验值。

在 PowerShell 中运行 `Get-FileHash .\ShadowChat-1.2.7-local-setup.exe -Algorithm SHA256`，
与 `SHA256SUMS.txt` 的同名记录核对。附件精确字节数与摘要见 `build-info.json`。
