# 导航与全局搜索反馈修复记录

日期：2026-11-05。基线为已发布的 1.2.3 测试版，工作区仍使用原分支。
这是进入 1.2.4 发布快照之前的阶段记录；1.2.4 的最终结果另见 `QA-1.2.4.md` 及交付回执。
本次为未发布的本地代码变更，不覆盖 `v1.2.3-test` 的源码、安装包、标签或附件。

## 变更

- 未选中导航的图标和文字统一为 `#5F6B7A`。
- 选中导航底框为 `#F8FBFC`，悬停为白色；保留红色选中图标、文字及键盘焦点。
- 消息、通讯录采用官方 Phosphor Fill 图标，其他入口保留原有图标。
- 图标着色保持源图的设备像素倍率，避免 150%／200% 下意外缩小。
- 全局搜索分类标题只由委托绘制；“更多”行不再叠加重复标题。
- 搜索摘要只移除与历史发送者、时间吻合的格式化 HTML 显示头；
  按发送者匹配仍使用原记录，正文中的日期／姓名、重要标记及文件名称保留。
- 最近两个版本的说明统一使用“更新内容”章节，未把本轮未发布的界面修复写进旧版说明。

## 本机验证

使用 Windows Qt 原生平台，在临时 Win32 桌面运行；不切换用户输入桌面。
测试资料均为临时合成账号和记录，未读取或改写用户真实聊天库。

| 缩放 | 测试项目 | 结果 |
|---|---|---|
| 100% | search_panel、popup_placement、history_context_navigation、history_refresh | 4 项通过 |
| 150% | search_panel、popup_placement | 2 项通过 |
| 200% | search_panel、popup_placement | 2 项通过 |

覆盖分类数量、更多分类、Enter 打开、Esc 关闭、紧凑／非紧凑／RTL／重要消息、
旧历史显示头、真实正文中的日期与姓名、元信息不符时保守保留、文件名、源记录不变、
导航图标形状／状态颜色、高缩放绘制、历史定位和阅读位置保留。

构建及回归日志位于 `dist/build-ui-feedback.log`、
`dist/regression-ui-feedback-100.log`、`dist/regression-ui-feedback-150.log`、
`dist/regression-ui-feedback-200.log`；控件渲染图位于 `dist/proof/ui-feedback/`。
原生屏幕捕获部分仍不可用，控件渲染及窗口属性检查不冒充真实桌面视觉或多机验收。
